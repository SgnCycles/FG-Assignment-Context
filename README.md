# FG - Webb application development - Assignment - Context - Dynamic Routes#

## Introduction ##
For this school assignment I have built a multipage website using React Context and dynamic routing.
The topic of the website is exploring meal recipes and categories using data from the "TheMealDB" API. Users have their own profile where they can browse categories and recipes, save/remove the favourites, and add/remove recipes and required ingredients to a shopping list. The shopping list also allows the user to mark the bought ingredients and save the data.
